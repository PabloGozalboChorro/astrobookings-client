# Commit

Usa la skill `committing-changes` para hacer commit de los cambios actuales. Pista: `$ARGUMENTS`.

1. Revisa `git status` y `git diff`.
2. Si hay cambios de naturaleza distinta, propón dividirlos en varios commits.
3. Muestra el mensaje propuesto y espera la confirmación antes de ejecutar `git commit`.
